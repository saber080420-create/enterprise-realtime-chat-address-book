## 复现

在 big-event 目录运行（本机向量服务需就绪）：

```powershell
mvn '-Dtest=org.itheima.ai.*Test' '-Dvector.integration=true' '-Dembedding.integration=true' '-Dretrieval.eval=true' test
```

这会同时执行功能回归和合成检索评测，不调用 DeepSeek。真实数据库集成只删除自己创建的随机测试 schema，不清空业务表。报告在 Maven surefire 输出中，检索结果标记为 RETRIEVAL_EVAL。

前端在 big-event-vue 目录：

```powershell
node --test src/utils/*.test.js
node node_modules/vite/bin/vite.js build
```
