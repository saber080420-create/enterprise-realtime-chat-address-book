适合展示 Java 后端 / AI 应用开发能力。当前是权限感知的 RAG 与结构化摘要应用，不是能自主选择工具、执行任务的完整 Agent。不要把个人项目写成真实公司的生产系统。

## 12 个高频追问

### 1. RAG 的链路是什么？

业务文档 → 纯文本处理/分片 → 本地 embedding → 向量索引。提问时先取授权且版本有效的候选 → 查询向量 → 余弦排序 → 复查原文 → 给 DeepSeek 生成 → 展示来源。关键词模式是保留的基线，没有自动与向量融合。

### 2. 为什么还需要 MySQL？

MySQL 保存权威业务内容、所有者、成员状态；PGVector 是可重建的检索副本。向量相似不意味着有权读取。当前小规模先做授权候选精确检索，没有上 HNSW。

### 3. 文档删了但向量还在，会泄露吗？

软删除后的文档不在当前有效候选里，旧向量无法提供上下文；命中后和查看原文时还会复查。物理清理尚未实现，历史已显示内容也不会自动消失。最后一次检查与发送之间仍有竞态窗口，不能说绝对强一致。

### 4. 为什么用内容指纹？

文档被编辑或权限范围变化后，旧索引不能作为当前内容使用。SHA-256 指纹结合资源字段和正文识别版本；模型/切分版本单独隔离。未变时复用，变化后完整生成向量再事务替换。

### 5. 为什么切成 600 字符、重叠 100？

这是当前可解释、可测试的起始参数，兼顾输入成本和边界信息。不是最优参数，也不是 600 token。后续需用代表性数据对照测试不同切分、top-k 和阈值。

### 6. 0.45 相似度是什么意思？

是当前余弦分数的筛选阈值，不是正确率或概率。阈值高可能漏召回，低可能引入无关资料；需要正负样例共同校准。当前只有小规模合成冒烟与演示，不宣称普适效果。

### 7. 为什么不是 WebSocket？

AI 输出是服务器到浏览器单向增量流，SSE 足够；原即时通讯仍用 WebSocket。使用 fetch 而非 EventSource，是为了 POST 请求体和 Authorization。

### 8. 取消为什么不能只 abort？

断开浏览器请求不代表上游生成已停止。服务端生成请求 ID，取消接口校验当前用户和 ID，关闭上游连接并确认释放。旧取消不能误停新请求。通用历史只保留成功且完整的对话对。

### 9. 摘要为什么不能直接展示流式 JSON？

半截 JSON 结构不完整，字段和引用可能错误。后端有界缓冲，完成后检查字段、类型、长度和来源 ID，再发送摘要事件。负责人/期限保留原文，不把发言人默认当负责人，不擅自推算日期。

### 10. 格式正确就说明模型没幻觉吗？

不是。引用存在只能证明用了允许的 ID，原文包含“小王”也不能证明任务一定归他。还需要语义质量评测和人工核对；提示词抗注入也不是安全边界，真正的权限和执行约束在代码里。

### 11. 怎么测试？

单元测试覆盖输入和输出校验；H2 执行真实 MyBatis SQL 验证权限条件；本机 HTTP 模拟验证供应商协议；真实 Ollama/PGVector 用隔离 schema 测试检索和事务；浏览器验证实际页面。H2 和模拟模型不能冒充生产数据库、真实模型质量或压力测试。

### 12. 这为什么还不叫 Agent？

当前是固定流程的检索与总结，没有模型选择工具、执行、观察结果再规划的循环。下一阶段可以加入受权限控制、人工确认和幂等保护的任务创建工具，但不能把现在的行动项列表说成已经自动执行。

## 学习优先级（围绕代码，不另开大课程）

1. 先理解一次请求：AiChatController → 模式服务 → ChatModelGateway → 前端事件处理。
2. 学会讲权限：AnnouncementKnowledgeMapper、DocumentKnowledgeMapper、GroupSummaryMapper。
3. 理解索引副本：DocumentVectorService、PgVectorStore 的候选、指纹和事务。
4. 理解异常：取消、无依据拒答、未同步、输出截断、结构校验失败分别怎样处理。
5. 能演示并解释一个真实缺陷：停止后立即重试问题，或软删除消息遗漏过滤。

开发过程中大量代码由 AI 辅助完成。面试如被问到应如实说明使用方式，重点展示你能理解设计、复现测试、定位边界并修改代码的能力；不要声称未经理解的内容都是独立手写。
