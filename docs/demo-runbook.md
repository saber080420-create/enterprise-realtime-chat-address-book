- 独立演示群为 AI摘要验收-20260908-01，ID 12，仅账号 110；合成消息 412–415。保留但不复用到真实业务群。
- 文档样例使用 docs/fixtures/knowledge-demo.txt。此前演示文档已移出，若上传新副本，需要再次同步。

## 演示顺序

1. 通用问答（1 分钟）：让助手写短周报，再追问；显示增量输出和 Token。长输出可停止后重试，说明取消不是只关浏览器连接。
2. 文档入库（1 分钟）：上传合成 TXT，打开原文。说明只对自己可见，文件不放公开静态目录。
3. 向量问答（2 分钟）：同步个人文档，再同步看复用；问“外出办事回来后，最迟什么时候交费用申请？”；展示来源，不承诺与关键词对比一定提升。
4. 无依据（1 分钟）：问随机无关问题，观察拒答及 Token 0；再问“金额上限”，说明资料未规定就不能编造数字。
5. 群摘要（2 分钟）：选择隔离演示群和包含 2026-09-08 19:27–19:31 的范围，检查两条行动项、小李期限未明确、部署未决定；打开原消息引用。
6. 边界与后续（1 分钟）：说明未做生产部署、压测和大规模质量评测；当前不自动创建任务，下一阶段才加 Agent 执行。

删除/撤回/离群演示会改变数据，单独确认后再做。此前已经验证个人文档移出后旧引用失效、旧向量不能召回，可用验收记录说明，不必每次重新删除。

## 遇到问题

- 登录跳转：重新登录，不重新配置 Key。
- 入口禁用：检查是否旧后端或向量未启用。
- 未建有效索引：先同步，不把关键词回答冒充语义检索。
- 摘要为空：确认群、时间、当前成员、自己的副本、入群时间和消息类型；不要把昵称当用户名查库。
- 摘要结构失败：缩小范围重试，保留错误证据；不展示未校验 JSON。
- 现场服务不可用：展示代码、自动化测试与已有验收记录，明确是录制/历史证据，不伪装实时成功。
